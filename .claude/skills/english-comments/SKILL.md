# Code comments

Every code comment and docstring you write or edit is in **English**, whatever it explains: technical details, business rules, domain concepts or decisions. Business context stays in the comment where it is relevant; it is not moved elsewhere.

This applies to all comment syntaxes (`#`, `//`, `/* */`, `{# #}`, `<!-- -->`) and to docstrings.

Only comments are affected. Strings the app shows to users (templates, labels, messages, validation errors) keep their current language.

{% load i18n %} {% comment %} The "Create publishing" dialog of the edition form and the "Create title" / "Create editorial" dialogs it opens on top of it. Sibling modals (never nested in each other nor in the edition form), driven by js/custom/publishing_dialogs.js: each form posts to its Gestión JSON API and the new row is added to the select that asked for it. Required fields carry an asterisk and, while empty, a hint (forms.RequiredHintsMixin). When an import's publisher matched no editorial, the publishing dialog offers to pick an existing one and remember the publisher's name as its alias (data-alias-url). Also the "Create artist" dialog of the edition form's artist pickers. Parameters: publishing_dialog, title_dialog, editorial_dialog, artist_dialog (the unbound forms). {% endcomment %}
